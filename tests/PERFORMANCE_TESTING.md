## 前提条件

在开始性能测试前，请确保满足以下条件：

1. 项目已成功编译，并且测试程序可用
2. 已安装Python 3及相关依赖（pandas和matplotlib）
3. 直播服务器已经启动并正常运行
4. 如果测试拉流性能，需要确保有一个推流源

## 快速开始

1. 进入项目根目录
2. 运行自动化测试脚本:

```bash
cd tests
./run_performance_tests.sh
```

3. 按照脚本提示选择测试类型并输入相关参数
4. 测试完成后，可以在`performance_results`目录下查看测试结果和性能报告

## 测试工具介绍

本项目提供了以下几种性能测试工具：

### 并发连接测试 (TestRtmpBenchmark)

用于测试RTMP服务器在高并发情况下的性能表现，可以模拟大量客户端同时推流或拉流。

```bash
# 手动运行方式
cd build
./TestRtmpBenchmark --clients 100 --duration 60 --server 127.0.0.1 --port 1935 --stream test --play
```

主要参数：
- `--clients`: 并发客户端数量
- `--duration`: 测试持续时间(秒)
- `--server`: 服务器IP地址
- `--port`: 服务器端口
- `--stream`: 流名称
- `--play`: 拉流测试模式
- `--publish`: 推流测试模式

### 端到端延迟测试 (TestRtmpLatency)

用于测量RTMP直播系统的端到端延迟，通过在推流内容中嵌入时间戳，计算从推流到拉流的时间差。

```bash
# 手动运行方式
cd build
./TestRtmpLatency --duration 60 --interval 1000 --server 127.0.0.1 --port 1935 --stream latency_test
```

主要参数：
- `--duration`: 测试持续时间(秒)
- `--interval`: 采样间隔(毫秒)
- `--server`: 服务器IP地址
- `--port`: 服务器端口
- `--stream`: 流名称

### 服务器性能监控 (server_monitor.sh)

用于在测试过程中监控RTMP服务器的CPU、内存、网络带宽和连接数等性能指标。

```bash
# 手动运行方式
cd build
./server_monitor.sh -s 127.0.0.1 -p 1935 -d 60 -o server_performance.csv -v
```

主要参数：
- `-s, --server`: 服务器IP地址
- `-p, --port`: 服务器端口
- `-i, --interval`: 采样间隔(秒)
- `-d, --duration`: 监控持续时间(秒)
- `-o, --output`: 输出CSV文件
- `-v, --verbose`: 输出详细信息

### 数据可视化 (visualize_perf_data.py)

用于分析性能测试数据并生成可视化报告。

```bash
# 手动运行方式
cd tests
python3 visualize_perf_data.py path/to/server_performance.csv --output report.pdf
```

主要参数：
- 第一个参数: CSV数据文件路径
- `--output, -o`: 输出报告文件名
- `--title, -t`: 报告标题
- `--no-show`: 不显示图形界面，只保存文件

## 测试指标说明

在性能测试中，我们主要关注以下几个指标：

### 并发连接测试指标

- **连接成功率**: 成功建立连接的客户端数量/总客户端数量
- **带宽使用**: 服务器的网络吞吐量(Mbps)
- **CPU使用率**: 服务器的CPU使用百分比
- **内存使用量**: 服务器的内存使用量(MB)

### 延迟测试指标

- **平均延迟**: 端到端传输的平均延迟时间(毫秒)
- **最大延迟**: 测试过程中观察到的最大延迟(毫秒)
- **95%百分位延迟**: 95%的请求延迟都小于该值

## 测试结果解读

测试完成后，会在`performance_results`目录下生成详细的测试报告，包括：

1. 原始测试日志(*.log)
2. 服务器性能数据(*.csv)
3. 性能分析报告(*.pdf)

性能报告包含以下图表：
- CPU使用率曲线图
- 内存使用曲线图
- 网络带宽曲线图
- 连接数曲线图
- 性能指标摘要表格

### 结果分析建议

- **CPU使用率**: 正常情况下应保持在70%以下，如果长时间超过90%，说明服务器CPU可能成为瓶颈
- **内存使用**: 应观察内存使用是否稳定，若持续增长可能存在内存泄漏
- **带宽使用**: 应关注是否接近网络硬件极限，通常千兆网卡的实际带宽上限在900Mbps左右
- **延迟指标**: 直播系统的平均延迟通常在1-3秒，如果超过5秒，需要检查系统配置或网络问题

## 常见问题

1. **测试程序无法运行**
   - 检查是否已成功编译项目
   - 确保有足够的系统权限运行测试程序

2. **连接失败率高**
   - 检查服务器是否正常运行
   - 确认防火墙是否允许RTMP端口访问
   - 检查系统文件描述符限制(ulimit -n)

3. **延迟测试无法正常工作**
   - 确保服务器支持RTMP协议的元数据传输
   - 检查网络连接是否稳定

4. **监控脚本无法自动检测进程**
   - 手动指定服务器进程ID: `./server_monitor.sh --pid <PID>`

5. **数据可视化失败**
   - 确保已安装Python和必要的依赖库: `pip3 install pandas matplotlib`
